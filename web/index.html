Architecture
CancerGPT Pipeline
01
Data Preprocessing
Ingests cBioPortal data: clinical patient/sample records, somatic mutations, copy number alterations, structural variants, and timelines. Standardizes formats and merges into unified patient records.
📄 01_data_preprocessing.py
02
Feature Engineering
Builds 155 ML-ready features per patient: one-hot mutation flags for 29 key genes, CNA profiles, TMB quantification, mutational signatures (SBS1-13), MSI proxy, and CIN index.
📄 02_feature_engineering.py
03
RAG Indexing
Builds a TF-IDF retrieval index over 103 patient summaries enriched with NCCN/ESMO guideline context. Used to retrieve similar cases and evidence during LLM consultation.
📄 03_rag_indexing.py
04
LLM Agent
Groq-powered clinical agent that loads patient profiles, retrieves RAG context, and generates evidence-tiered treatment recommendations with multi-turn consultation support.
📄 04_llm_agent.py
05
API Server
FastAPI backend exposing /consult/load, /consult/chat, /consult/report, /patients and analytics endpoints. Serves this web interface.
📄 api_server.py
